# ยินดีต้อนรับสู่คู่มือการพัฒนาสำหรับ Antigravity

## ข้อมูลพื้นฐาน

- **โทนสีหลักของระบบ**: `#e83e8c` (Pink-Rose) ใช้สำหรับองค์ประกอบหลักเพื่อความสวยงามและเป็นเอกลักษณ์

## กฎการพัฒนา

- พัฒนาโดยเน้น **Mobile-First** และดีไซน์แบบ **Premium**
- ใช้ระบบฐานข้อมูลร่วมกับ `skj2025` ผ่าน Docker Network `skj2025_default`
- การเข้าถึงระบบชุมนุมจำกัดเฉพาะนักเรียนที่มีสถานะ **"1/ปกติ"** เท่านั้น
- นักเรียนสถานะอื่นๆ สามารถเข้าดูผลการเรียนได้เพียงอย่างเดียว
